# KRISH.OS — Portfolio

An interactive engineering portfolio for Krish Italiya.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Import this repository into Vercel. The production build uses `npm run build`.

## Content accuracy

The content is based on the supplied resume and public repositories. Project claims distinguish implemented capabilities from future plans. Update `src/data/portfolio.ts` as achievements, links, and evidence are verified.
